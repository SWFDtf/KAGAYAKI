# KAGAYAKI Dokumentation — Geschichten für Menschen

**KAGAYAKI** ist eine Visual-Novel-Engine auf Basis von Java 21. Du schreibst Dialoge, Entscheidungen und Szenen in leicht lesbaren `.vjava`-Dateien. Wenn du tiefere Programmlogik brauchst, bindest du Java direkt ein — ohne Umwege.

---

## Warum dieses Projekt für Menschen existiert

Viele Werkzeuge für Spieleentwicklung zwingen Autorinnen und Autoren in komplexe Oberflächen oder unverständliche Skriptsprachen. KAGAYAKI geht einen ruhigeren Weg:

- **Lesbare Texte statt Klammer-Salat:** Deine Geschichte steht im Mittelpunkt. Eine einfache Einrückung zeigt, was zusammengehört.
- **Zwei Fenster für entspanntes Arbeiten:** Im Studio-Modus siehst du links deine Werkzeuge und rechts sofort das laufende Spiel.
- **Barrierefreiheit von Anfang an:** Vorlesefunktion (Text-to-Speech), Tastatur- und Gamepad-Steuerung sowie klare Kontraste sind fest eingebaut.
- **Volle Kontrolle bei Bedarf:** Entwicklerinnen und Entwickler können jederzeit sauberen Java-21-Code in ihre Szenen einbetten.
